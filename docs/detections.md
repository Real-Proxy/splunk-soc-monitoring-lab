# SSH Detections

## Failed Login Detection

Detects SSH authentication failures to identify brute-force or password spraying attempts.

---

## Top SSH Attack Sources

Identifies source IPs generating large numbers of SSH authentication attempts.

---

## Most Targeted Servers

Highlights systems receiving high SSH traffic volume.

---

## Source to Destination Relationships

Maps attacker-to-target relationships for investigation purposes.

# HTTP Detections

## 404 Scanning Detection

Detects excessive HTTP 404 responses that may indicate directory enumeration or reconnaissance activity.

---

## DirBuster Detection

Detects OWASP DirBuster scanning activity used for automated directory brute-forcing.

---

## HTTP Status Code Analysis

Analyzes HTTP response distributions such as 200, 404, and 400 responses.

---

## Potential Scanning Activity

Identifies suspicious high-volume request behavior associated with automated scanning tools.
